# ResumeAI Analyzer

An AI-powered Resume Analyzer built with Python, Streamlit and Google Gemini.

## Features

- ATS Resume Score
- Job Match Score
- Resume Summary
- Skills Detection
- Missing Skills
- AI Suggestions
- Cover Letter Generator
- Resume PDF Report
- Resume History (SQLite)

## Tech Stack

- Python
- Streamlit
- Google Gemini API
- SQLite
- ReportLab
- Plotly

## Installation

```bash
pip install -r requirements.txt
streamlit run app.py
